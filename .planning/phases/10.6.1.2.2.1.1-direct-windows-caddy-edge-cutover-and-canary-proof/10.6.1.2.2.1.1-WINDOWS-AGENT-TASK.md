## Step 2: Shadow Canary Only

Do not touch all 9 accounts.

Use only canary worker `shared-6`.

Start the Windows-side API in shadow mode:

```powershell
powershell -ExecutionPolicy Bypass -File .\infra\windows-block\start-public-api.ps1 -ListenHost 127.0.0.1 -ListenPort 4011 -AllowedWorkerIds shared-6
```

Switch `Caddy` to shadow mode:

```powershell
powershell -ExecutionPolicy Bypass -File .\infra\windows-block\activate-public-edge.ps1 -Mode shadow -Apply
```

Run the local canary proof:

```powershell
powershell -ExecutionPolicy Bypass -File .\infra\windows-block\probe-public-api.ps1 -BaseUrl http://127.0.0.1:4011 -IncludeChatProbe -WorkerId shared-6 -EnsureWorkerStarted -StopWorkerWhenDone
```

Then write `10.6.1.2.2.1.1-SHADOW-CANARY-PROOF.md` with:

- exact command outputs
- whether `shared-6` had to be started
- whether it was stopped again
- whether `healthz` passed
- whether `v1/models` passed
- whether `v1/chat/completions` passed
- whether any rollback was needed already at shadow stage
- explicit confirmation that the other 8 workers were left untouched
