## Current Hidden Runtime Verdict

Current host hidden runtime is rejected for rollout use.

Why:
- it no longer fails only as vague selector drift
- it now has bounded evidence showing startup instability and Cloudflare challenge behavior after the visible-auth handoff
- the same durable profile can behave differently in visible auth versus hidden runtime, so the project must not treat hidden runtime as a harmless display choice

Verdict: `do_not_use_for_phase_11`

## Alternative Candidate Verdict

Alternative candidate reviewed: `docker_headed_xvfb`

What was confirmed:
- the candidate is explicit in code and compose
- it runs a real headed browser under Xvfb with browser access available
- it is not just a renamed copy of the host hidden runtime

What failed:
- live bootstrap on the candidate still hit ChatGPT challenge flow
- the candidate therefore did not clear the core runtime gate of reaching a usable ChatGPT fresh-chat surface

Verdict: `candidate_not_selected`

## Selected Runtime For Phase 11

Selected Runtime For Phase 11: none
