That script already proves:

- one named worker starts in `CompactCorner`
- the worker reaches `Temporary Chat`

## Research Conclusion

This phase does not need a new browser runtime design. It only needs:

1. a seven-worker wrapper around the existing single-worker proof path
2. one durable result artifact for the local worker matrix
3. one operator-facing rerun contract in docs

## Practical Constraints

- The local operator PC is still the machine hosting the browser runtime.
- Compact-visible proof is valid for local confidence only.
- The result must be recorded worker-by-worker, not summarized vaguely as "it worked on my machine."
