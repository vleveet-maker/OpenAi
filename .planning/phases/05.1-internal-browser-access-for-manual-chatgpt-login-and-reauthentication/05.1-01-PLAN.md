  <name>Task 1: Build a custom worker runtime with a persistent display and browser viewer services</name>
  <files>infra/docker-compose.yml, infra/worker-runtime/Dockerfile, infra/worker-runtime/start-worker-runtime.sh</files>

  <action>Create `infra/worker-runtime/Dockerfile` with `FROM mcr.microsoft.com/playwright:v1.58.2-jammy`, install `fluxbox`, `x11vnc`, `novnc`, and `websockify`, copy `infra/worker-runtime/start-worker-runtime.sh`, and set that script as the container command entrypoint target. Create `infra/worker-runtime/start-worker-runtime.sh` that exports `DISPLAY=:99`, starts `Xvfb :99 -screen 0 1280x1024x24`, starts `fluxbox`, starts `x11vnc -display :99 -rfbport ${BROWSER_ACCESS_VNC_PORT:-5900} -forever -shared -localhost -nopw`, starts `websockify --web /usr/share/novnc/ ${BROWSER_ACCESS_HTTP_PORT:-6080} localhost:${BROWSER_ACCESS_VNC_PORT:-5900}`, and then runs `npm run dev --prefix workers/agent`. Update every worker service in `infra/docker-compose.yml` to use `build: ./worker-runtime`, set `DISPLAY=:99` and `BROWSER_ACCESS_HTTP_PORT=6080`, keep the worker services on `worker-net` only, and do not publish any host ports for browser access.</action>
  <verify>rg -n "x11vnc|websockify|fluxbox|BROWSER_ACCESS_HTTP_PORT|build: \\./worker-runtime" infra/docker-compose.yml infra/worker-runtime/Dockerfile infra/worker-runtime/start-worker-runtime.sh</verify>
