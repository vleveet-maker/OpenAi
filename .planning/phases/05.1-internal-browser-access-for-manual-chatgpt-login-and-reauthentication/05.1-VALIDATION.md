# Phase 05.1 - Validation Strategy

> Per-phase validation contract for internal-only worker browser access.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | `vitest` in `services/control-api` and `workers/agent` |
| **Primary package** | `services/control-api` |
| **Quick run command** | `cmd /c npm.cmd test --prefix services/control-api -- internal-browser-access` |
| **Full suite command** | `cmd /c npm.cmd test --prefix services/control-api && npm.cmd test --prefix workers/agent` |
| **Estimated runtime** | ~12 seconds |

## Sampling Rate

- After each worker-runtime task, run the `workers/agent` test subset for browser access.
- After each control-api or edge task, run the `services/control-api` browser access tests.
- Before phase sign-off, run the full `services/control-api` and `workers/agent` test suites.
- Before `$gsd-verify-work`, complete one live manual login or reauth smoke test against the Docker stack.
