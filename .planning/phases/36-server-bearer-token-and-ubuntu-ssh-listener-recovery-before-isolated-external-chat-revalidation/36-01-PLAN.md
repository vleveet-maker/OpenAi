It must write both JSON and Markdown artifacts plus `infra/data/post-phase35-server-token-ssh-listener-recovery/latest.json`.
</action>
<acceptance_criteria>
- wrapper exists and passes PowerShell parser checks
- artifact contains `tokenResolution.status`, `tokenResolution.source`, and `tokenResolution.secretValueRecorded=false`
- artifact contains per-host Ubuntu SSH reachability truth
- artifact contains listener truth for `14021..14027` and `14040`
- artifact does not contain bearer-token values, SSH passwords, cookies, local storage, or profile secrets
- wrapper verdict is constrained to `ready_for_revalidation` or `hold_rollout` for the recovery stage
</acceptance_criteria>
</task>
